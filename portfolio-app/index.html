Northwind AI Enterprise Platform

Uma solução corporativa unindo Engenharia de Dados robusta, orquestração de IA autônoma segura e Dashboard executivo estilo Power BI.

O Desafio de Negócio

A base de dados transacional clássica Northwind (pedidos, clientes, fornecedores e produtos) precisava ser modernizada para viabilizar análises corporativas de alta performance, onde tomadores de decisão pudessem consultar métricas de negócio tanto visualmente quanto via linguagem natural com agentes de IA.

A Solução Desenvolvida

Construção de uma plataforma de dados distribuída ponta a ponta:

  • ✓ Data Pipeline Medallion: Ingestão estruturada de PostgreSQL, enriquecimento via dbt (Bronze, Silver Star Schema, Gold Agregações) orquestrado com Airflow.
  • ✓ Segurança Rigorosa (AST Sanitizer): Tradução de linguagem natural para SQL com proteção contra queries destrutivas (DROP, DELETE, ALTER, INSERT) através de árvore sintática abstrata (AST).
  • ✓ Model Context Protocol (MCP): Servidor oficial padronizado para expor esquemas, metadados e ferramentas analíticas para LLMs.
  • ✓ Dashboard BI React 18: Interface estilo Power BI com 14 visualizações analíticas, suporte Dark/Light mode e Chatbot contextual.

Segurança Crítica

Prevenção de SQL Destrutivo via Análise AST

Problema: LLMs em sistemas Text-to-SQL podem alucinar ou ser induzidas por prompts maliciosos a executar comandos DROP, DELETE ou ALTER.

Solução: Implementação de validador sintático baseado na biblioteca sqlglot. A query gerada pelo SQL Agent é convertida em Árvore Sintática Abstrata (AST) e rejeitada imediatamente se não for estritamente do tipo SELECT.

Engenharia de Dados

Modelagem Dimensional Star Schema com dbt

Problema: O banco relacional Northwind é normalizado (3NF), ineficiente para consultas analíticas de alta performance e agregações em tempo real.

Solução: Modelagem em dbt criando tabelas de dimensões (dim_customers, dim_products, dim_employees) e tabela fato (fct_orders) com surrogate keys e 16 testes de integridade referencial.

Integração dbt + Airflow

Execução Modular sem Travamento de Containers

Problema: Bibliotecas de integração direta apresentavam inconsistências de versões de Python entre o container do Airflow e o dbt core.

Solução: Implementação com BashOperator e TaskGroups modulares, isolando a execução das camadas Bronze, Silver e Gold em tarefas independentes com logs estruturados.

Model Context Protocol

Padronização de Ferramentas via Protocolo Oficial MCP

Problema: Cada framework de agentes (LangChain, CrewAI, AutoGen) utiliza schemas proprietários para chamada de ferramentas (tools).

Solução: Criação de um servidor MCP nativo expondo ferramentas universais (inspect_schema, run_safe_query, get_kpis, recommend_chart), compatível com qualquer cliente de IA do mercado.
